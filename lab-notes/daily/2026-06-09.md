## 2026-06-09 — Evaluation Framework + Model Iterations
**Last commit:** `6c97253` — "test: add jepa embedding quality validation tests"

**Files added:**
- `test_jepa_embeddings.py` — Unified evaluation suite (embedding sanity + linear probe)
- `test_jepa_representation.py` — Unit tests for embedding quality
- `jepa-model/` — Model checkpoints and analysis reports (iterations 1-4)

**Decisions:**
- **Evaluation framework**: `test_jepa_embeddings.py` became standard evaluation with 3 sections: embedding sanity (cosine similarity, PCA, t-SNE), linear probe (next-day direction prediction), unified verdict
- **Multiple model iterations**: Models 1-4 with different hyperparameters (embed_dim 256→64, different mask ratios)
- **Model iteration 4**: embed_dim=64, mask_ratio=0.7, trained for 50 epochs
- **Unit tests**: temporal smoothness, mask-ratio stability, macro-feature correlation, train/test consistency, variance spread

**Working:** Evaluation pipeline robust and automated. t-SNE visualizations showed some temporal structure. PCA showed 3-6 effective dimensions.
**Not working:** **All iterations FAILED** — cosine similarity still ~0.998-0.999 across all models. Linear probe never exceeded 57.0%. Model 3 had rank collapse (90% variance in 3 dims). Model 4 (64-dim) slightly better but still failed. No variance/covariance regularization in the loss.
