## 2026-06-10 — VICReg Regularization
**Last commit:** `c4541c4` — "variance and covariance losses"

**Files modified:** `jepa-training.py` and `test_jepa_embeddings.py` significantly rewritten

**Decisions:**
- **VICReg regularization added**: Variance loss + covariance loss added to JEPA objective
  - `vicreg_eval()` computes: variance loss (ReLU(γ - std)), covariance loss (off-diagonal squared sum), effective rank, max correlation
  - Total loss = prediction_loss + λ_v * variance_loss + λ_cv * covariance_loss
- **Configurable hyperparameters**: `Training_configuration` and `JEPA_parameters` dataclasses with env-var overrides
- **Validation loop**: `evaluate()` function runs on test set every save_interval epochs
- **Loss curve plotting**: `plot_all_curves()` saves component loss curves (total, prediction, variance, covariance)
- **Normalization**: Both EMA targets and encoder outputs use `F.normalize(dim=-1)` in addition to LayerNorm

**Working:** VICReg loss components computed correctly. Training loop tracked all 4 loss components. Validation set evaluation worked.
**Not working:** VICReg hyperparameters (λ_v=0.5, λ_cv=0.45) may not have been optimal. Still early in VICReg exploration.
