## 2026-05-26 — MPC-VAR + GRPO Foundations
**Last commit:** `6601fe0` — "refactor: update tensor key references to use _keys consistently"

**Files:**
- `.gitignore`, `LICENSE`, `README.md`, `requirements.txt`

- `individual_stocks/` — PCA_engine, clean_sector_etfs, cleanup, grpo, pull_sector_etfs, stock_universe, test_grpo_simple

**Decisions:**
- **Two-track architecture**: Classical MPC-VAR portfolio optimization (main track) + GRPO/RL track under `individual_stocks/`
- **MPC formulation**: State = [logWealth, w1...w7]^T, dynamics x_{k+1}=Ax_k+Bu_k, solved via OSQP QP
- **VAR forecasting**: 7-asset vector autoregression (AGG, GLD, SLV, SPY, VTI, VEA, VWO) for return predictions
- **GRPO module**: Custom `GRPOContinuousLoss` class (no critic, group-relative advantage) using TorchRL
- **Data pipeline**: `StockCleaner` class for parquet-based OHLC/volume processing with feature engineering (log returns, HL spread, RVOL)

**Working:** MPC planner solved OSQP QP problems. MarketSimulator modeled log-wealth + weight drift. Unit tests passed (drift/rebalance, flash crash, no short selling, risk aversion). Min-variance benchmark ran end-to-end. GRPO loss forward/backward pass worked on Pendulum-v1 and HalfCheetah-v4.
**Not working:** `test_grpo_simple.py` had shape bug (action_log_prob needed unsqueeze). kl_divergence tensor shape inconsistency across reduction modes. No JEPA model yet.
