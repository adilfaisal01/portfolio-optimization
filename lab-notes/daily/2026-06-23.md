## 2026-06-23 — Time-Varying Risk Covariances
**Last commit:** `9a5bd82` — "feat: extend cost_matrices to support time-varying risk covariances"

**Files modified:** `dynamics.py`

**Decisions:**
- **Time-varying risk covariances**: `cost_matrices()` accepts `r_hat_cov` as either `(n_assets, n_assets)` or `(N_horizon, n_assets, n_assets)` — per-step covariance matrices
- **Per-step Q matrices**: Instead of one Q matrix repeated N times, each time step can have its own risk covariance
- Enables VAR forecast_cov output (which provides covariance per forecast step) to be used directly

**Working:** MPC planner now supported time-varying risk. Backward compatible with static covariance.
**Not working:** VAR model's `forecast_cov()` returns a single covariance matrix (not per-step), so time-varying feature wasn't actually being used yet.
